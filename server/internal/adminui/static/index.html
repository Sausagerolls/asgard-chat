Push notifications

The official Asgard apps get notifications through the Asgard push relay automatically; you don't need any keys. Upload your own Apple and Google keys below only if you build and sign the apps yourself (then set ASGARD_PUSH_RELAY=off). Notifications only ever carry encrypted data; each phone decrypts its own.

Apple (iPhone, iPad, Mac)

developer.apple.com › Certificates, IDs & Profiles › Keys › + › tick Apple Push Notifications service (APNs). Download the .p8 file. The key must belong to the team that owns the app's bundle ID: if you use a build of Asgard you signed yourself, use your own key and your own bundle ID.

Google (Android)

console.firebase.google.com › your project › Project settings › Service accounts › Generate new private key. Use the Firebase project the Android app was built with.
